# MBA-DPMM: Modelling Serological Multiplex Bead Assay Responses in Malaysia

## About this repository <a name="AboutthisRepository"></a>

This repository provides the **a simulated dataset, scripts, and supporting materials** required to reproduce the analyses presented in the paper:

**_Modelling serological multiplex bead assays responses: A case study from Malaysia_**

The project implements a **Dirichlet Process Mixture Model (DPMM)** framework to model multiplex bead assay (MBA) serological responses and integrates **spatial analysis** for epidemiological interpretation.  
All materials are provided to ensure **transparency, reproducibility, and reuse**.

---

## Repository structure <a name="Structure"></a>

This repository contains:

### Data

**`data/simulate_MBA_data.R`**, 
R simulation script used to generate the `data_MBA_modelling.csv` dataframe.

**`data/data_MBA_modelling.csv`** 
The primary simulated dataset, which shares similar characteristics with the empirical data used in the analysis. It contains individual-level multiplex bead assay measurements and socio-economic covariates.

**`data/data_MBA_modelling.txt`**
Codebook associated with the `data_MBA_modelling.csv` dataframe.
---

### Code

**`code/code_MBA_modelling.R`**  
Main R script containing the **full analysis workflow**

This script assumes that:
- The dataset `data_MBA_modelling.csv` is available in the R session. 
- The function defined in `crp_gibbs_fun.R` has been sourced beforehand.
- The object `mesh_sabah.rds` has been loaded in the Global Environment.

**`code/crp_gibbs_fun.R`**  
R implementation of the **Dirichlet Process Mixture Model (DPMM)** using a Chinese Restaurant Process Gibbs sampler, following the methodology described in Li et al.  
This script must be sourced before running the main modelling script.

**`code/mesh_sabah.rds`**  
Precomputed **mesh grid for Sabah (Malaysia)** used in the spatial component of the analysis.  
The object can be loaded in R using:

```r
readRDS("scripts/mesh_sabah.rds")
```

**`code/gadm41_MYS_shp`** 
This subfolder `gadm41_MYS_shp`stores the shapefiles of Malaysia downloaded from the GADM spatial database.

Reference:  
Li Y, Schofield E, Gönen M. A tutorial on Dirichlet process mixture modeling. Journal of mathematical psychology. 2019 Aug 1;91:128-44.

## Reproducibility <a name="Reproducibility"></a>

To run the analysis:

1. Clone or download this repository.

2. Open an R session.

3. Source the DPMM function:
source("code/crp_gibbs_fun.R")

4. Run the main analysis script:
source("code/code_MBA_modelling.R")

The R scripts provided in this repository represent the exact analytical pipeline used in the paper. However this repository includes a simulated dataset specifically designed to mirror the structure and statistical properties of the original empirical data. Consequently, while the code is fully functional, the resulting numerical values, tables, and plots generated by running this workflow will not perfectly match those presented in the published manuscript.
