# MBA-DPMM: Modelling Serological Multiplex Bead Assay Responses in Malaysia

## About this repository <a name="AboutthisRepository"></a>

This repository provides the **data, code, and supporting materials** required to reproduce the analyses and results presented in the paper:

**_Modelling serological multiplex bead assays responses: A case study from Malaysia_**

The project implements a **Dirichlet Process Mixture Model (DPMM)** framework to model multiplex bead assay (MBA) serological responses and integrates **spatial analysis** for epidemiological interpretation.  
All materials are provided to ensure **transparency, reproducibility, and reuse**.

---

## Repository structure <a name="Structure"></a>

This repository contains:

### Data

**`data/data_MBA_modelling.csv`**  
Primary dataset used in the analysis.  
It contains individual-level multiplex bead assay measurements and associated covariates used for statistical modelling and spatial inference.

---

### Scripts

**`scripts/MBA_modelling_script.R`**  
Main R script containing the **full analysis workflow**, including:
- data preprocessing  
- model fitting  
- posterior inference  
- visualization of results  

This script assumes that:
- the dataset `data_MBA_modelling.csv` is available in the R session  
- the function defined in `crp_gibbs_fun.R` has been sourced beforehand  

**`scripts/crp_gibbs_fun.R`**  
R implementation of the **Dirichlet Process Mixture Model (DPMM)** using a Chinese Restaurant Process Gibbs sampler, following the methodology described in Li et al.  
This script must be sourced before running the main modelling script.

Reference:  
Li Y, Schofield E, Gönen M. A tutorial on Dirichlet process mixture modeling. Journal of mathematical psychology. 2019 Aug 1;91:128-44.

---

### Spatial data

**`scripts/mesh_sabah.rds`**  
Precomputed **mesh grid for Sabah (Malaysia)** used in the spatial component of the analysis.

readRDS("scripts/mesh_sabah.rds")

## Data sources

**Serological data**: Generated and processed as described in the associated manuscript.

**Spatial boundaries**: Derived from the Global Administrative Areas (GADM) database (https://gadm.org).

No personally identifiable information is included in this repository.

All data included are intended for research and educational use.

## Reproducibility <a name="Reproducibility"></a>

To reproduce the analysis:

1. Clone or download this repository.

2. Open an R session.

3. Source the DPMM function:
source("scripts/crp_gibbs_fun.R")

4. Run the main analysis script:
source("scripts/MBA_modelling_script.R")

All figures, tables, and numerical results reported in the paper are generated by the scripts contained in this repository.
This ensures fully reproducible results using the provided dataset and functions.
